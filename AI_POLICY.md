# AI contribution policy

Contributors may use AI tools when working on Riven. The person submitting the contribution remains responsible for it: understand the proposed changes, review generated code and documentation, verify factual and technical claims, and make sure the result follows project requirements.

Before asking an AI tool to draft an issue or pull request, check Riven's open issues, discussions, and pull requests. Do not submit a duplicate report or feature request, or open a pull request for work that is already being handled. Add context or offer help in the existing issue, discussion, or pull request instead.

Spamming issues or pull requests, or creating duplicate issues or pull requests, will result in a ban from the project. Check for existing reports and work in progress first; add information to the existing issue or pull request instead of opening another one.

For bugs in `RCP` or `aioquic`, report them to the relevant upstream project rather than opening a Riven issue. See the [contribution guide](CONTRIBUTING.md#before-you-start) for links and contribution instructions.
